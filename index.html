Projects

Arduino Traffic Light System

Arduino · C++ · LEDs · Buzzer

A traffic light controller built from three LEDs and a buzzer, wired through a shared ground rail. Started as a simple red/yellow/green sequencer and is being rebuilt as a proper state machine with audio patterns and a night mode. Next step is adding a pedestrian button and an ultrasonic sensor for adaptive timing once I've got more jumper wires.

Patient Monitor Concept

Arduino · Signal states

A repurpose of the traffic light hardware into a monitoring concept: green for a normal heartbeat, yellow for a warning state, and red with a constant buzzer for an abnormal reading. Same components, different problem — a good exercise in designing state logic that means something.

Mallet Slots

Python

A Python slot machine game built while learning the language from scratch, following an earlier number-guessing game project. Focused on getting comfortable with control flow, randomness, and structuring a small program end to end.
